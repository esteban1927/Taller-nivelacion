# Taller de Nivelación PI a PII

Este repositorio contiene la solución a los ejercicios prácticos del taller de nivelación en Java.

## Contenido

- Calculadora Básica (`CalculadoraBasica.java`)
- Contador de Vocales y Consonantes (`ContadorVocalesConsonantes.java`)
- Invertir una Cadena (`InvertirCadena.java`)

## Instrucciones de Ejecución

1. Clona el repositorio:
  ```bash
   git clone [https://github.com/esteban1927/Taller-nivelacion.git](https://github.com/esteban1927/Taller-nivelacion.git)
   ```
